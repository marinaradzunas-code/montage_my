# Свой проект: от запуска до первого ролика

Это учебная основа, а не библиотека чужих монтажей. Демосцены показывают приёмы; агент должен создавать сценарий по вашей речи, а не копировать их в каждый ролик.

1. Распакуйте архив в папку без кириллицы и пробелов в пути. Откройте её в Claude Code или Codex и попросите: «Установи проект по разделу „Установка через ИИ-агента“ из README, затем запусти студию».
2. Без агента на Windows — SETUP.cmd, затем START-STUDIO.cmd; нужны Node.js, Python и FFmpeg. Проверьте в студии Motion-Examples и демо стилей (Style1-Split, Style2-Fullscreen, Style3-Author).
3. Шрифт монтажа — Coolvetica: скачайте бесплатно с https://typodermicfonts.com/desktop и положите файл в `public/fonts-local/` (шаги — в README.md этой папки). Передавать файл шрифта друг другу лицензия не разрешает. Без него будет Tahoma.
4. Настройте editing-profile.json: шрифт, субтитры, нарезка, кадрирование и стиль. Эти параметры применяются к следующему импорту.
5. Дайте агенту путь к своему видео (на Windows можно перетащить файл на IMPORT-VIDEO.cmd). Импорт — черновой технический проход: он не выбирает лучший дубль и не создаёт смысловые анимации сам.
6. Дайте агенту задание ниже. Доступ к ИИ настраивается в самом агенте.
7. Проверьте ролик, поправьте текст и ключи в Studio, экспортируйте через EXPORT.cmd.

## Задание агенту

> Прочитай AGENTS.md, MONTAGE_RULES.md и motion-direction.json. Импортируй мой файл [путь]. Сначала сравни дубли по смыслу и сохрани выбранные/отклонённые интервалы с причинами; если выбор неоднозначен, спроси. Для каждой фразы составь план: предмет → действие → результат. Выбирай smooth/bounce/morph по смыслу, не копируй демонстрационный сюжет. Запроси недостающие материалы. Если нужен стиль автора — следуй разделу «Стиль автора — белый фон и крупные слова» в MONTAGE_RULES.md. Используй шрифт из editing-profile.json, проверяй паузы, зависания сцен, яркость и финальную часть мысли. Сохрани редактируемую композицию и открой её в Studio. Перед выдачей запусти scripts/check-frames.py, посмотри лист кадров, проверь рендер и сообщи, какие проверки действительно выполнены.

## Свой стиль монтажа

Стиль описывают агенту словами один раз: шрифт и размер субтитров, 50/50 или
полноэкранные объяснения, светлая/тёмная тема, насколько плотно резать паузы,
какие анимации нравятся (можно приложить референс). Агент переносит машинные
настройки в `editing-profile.json`, а словесные правила — в `MONTAGE_RULES.md`.
После этого стиль применяется к каждому следующему видео без повторного
описания.

## Где менять поведение

- editing-profile.json — исходные настройки импорта.
- scripts/import-video.py — техническая обработка и генерация клипов.
- motion-direction.json и AGENTS.md — планирование агентом.
- src/MotionExamples.tsx — кривые smooth/bounce/morph.
- src/generated — собственные редактируемые монтажи (не публикуются).
- src/local — собственные дополнительные композиции (не публикуются).

Видео, голос, субтитры и результаты импорта сохраняются локально в `public/projects` — резервируйте их отдельно. Если ведёте проект в git, отправляйте туда только код и обезличенные примеры. Перед push: `node scripts/check-template.cjs`, `npm run lint` и тесты из README. Не используйте git add -f для личных файлов.
