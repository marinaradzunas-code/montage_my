# Шаблон ИИ-монтажа вертикального видео

Шаблон для учеников Павла Радкевича (контент-продюсер): монтаж вертикальных
роликов вместе с ИИ-агентом — Claude Code, Codex или другим. Внутри — рабочий
импорт видео (распознавание речи, удаление пауз, субтитры), набор анимированных
сцен, правила монтажа и описание стиля автора.

Импорт — первый проход монтажа: локально распознаёт речь, предлагает удаление
пауз, создаёт редактируемые клипы и субтитры. Выбор дублей по смыслу, проверка
вдохов и подбор иллюстраций делает ИИ-агент по AGENTS.md.

## Быстрый старт (Mac и Windows)

1. Распакуйте архив в папку без кириллицы и пробелов в пути, например
   `~/montage` на Mac или `C:\montage` на Windows.
2. Откройте эту папку в Claude Code или Codex и напишите:

   > Установи проект по разделу «Установка через ИИ-агента» из README, затем
   > запусти студию и покажи демо-композиции.

3. Когда студия открылась, дайте агенту своё видео и задание из
   [GETTING_STARTED.md](GETTING_STARTED.md).

## Установка через ИИ-агента

Агенту нужно:

1. Проверить, что в PATH есть `node` (LTS), `python` 3.11 или новее и `ffmpeg`
   с `ffprobe`; чего нет — поставить (на Mac: `brew install node python ffmpeg`).
2. Выполнить `npm install` — он же создаёт заглушки в `src/generated` и
   `src/local` и чинит горячие клавиши Studio.
3. Создать окружение Python `python -m venv .venv` и поставить распознавание речи:
   - Windows: `.venv\Scripts\python.exe -m pip install faster-whisper==1.2.1 "av<19" "opencv-python-headless>=4.8,<5"`
   - Mac и Linux: `.venv/bin/python -m pip install faster-whisper==1.2.1 "av<19" "opencv-python-headless>=4.8,<5"`

   `"av<19"` обязателен: с PyAV 19 faster-whisper 1.2.1 падает с ошибкой
   `metadata_errors`. OpenCV нужен, чтобы кадр камеры строился по лицу.
4. Запустить студию: `npm run dev`.

Установка нужна один раз. Дальше в новом чате достаточно открыть ту же папку
проекта — всё уже стоит, агент сразу берёт видео.

Первый импорт скачает модель Whisper small (около 460 МБ) в `.models` — дальше
распознавание идёт локально без интернета. Правила монтажа для агента лежат в
`AGENTS.md` и `MONTAGE_RULES.md`: их следует прочитать до первой правки.

## Команды без агента

Файлы `.cmd` — для Windows: `SETUP.cmd` ставит зависимости, видео
перетаскивается на `IMPORT-VIDEO.cmd` (дождитесь `READY`), `START-STUDIO.cmd`
открывает студию, `EXPORT.cmd` выгружает ролик в `out`.

На Mac то же самое командами из папки проекта:

- импорт: `.venv/bin/python scripts/import-video.py "путь/к/видео.mp4"`
- студия: `npm run dev`
- экспорт: `node scripts/export-video.cjs`

Просто перетащить видео в окно Studio — это добавление медиа, оно не запускает
распознавание. Исходник при импорте копируется, а не изменяется.

## Что лежит в архиве

Это шаблон: видео в нём нет, каждый работает со своим материалом.

| Путь                                                                                                | Что это                                                          |
| --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `src/Root.tsx`                                                                                      | список композиций шаблона                                        |
| `src/MotionExamples.tsx`, `src/CarouselStory.tsx`, `src/PromptExamples.tsx`, `src/MontageStory.tsx` | готовые сцены, которые можно переиспользовать                    |
| `src/StyleDemo.tsx`                                                                                 | демо двух стилей: `Style1-Split` и `Style2-Fullscreen`           |
| `src/ProjectGuides.tsx`                                                                             | сетка и безопасные зоны поверх кадра                             |
| `scripts/import-video.py`                                                                           | импорт видео: распознавание речи, удаление пауз, субтитры        |
| `scripts/apply-research.py`                                                                         | скачивание проверенных материалов и пересборка ролика со сценами |
| `MONTAGE_RULES.md`, `AGENTS.md`                                                                     | правила монтажа и инструкция для ИИ-агента                       |

После клонирования доступны семь композиций: `Motion-Examples`, `Scene-Carousel`,
`Scene-Prompts`, `Chips-Library`, `Scene-Interface`, а также `Style1-Split` и
`Style2-Fullscreen` — витрина двух стилей на обезличенном материале (вместо камеры —
заглушка «Здесь ваше видео»). Всё это код и картинки из репозитория, ничего не
скачивается. Свои ролики появятся рядом после первого импорта.

В демо Style1/Style2 и импортированных композициях стиль переключается пропом `fullScreenExplanation`:
`false` — компоновка 50/50 (графика сверху, человек снизу, субтитры Y=960),
`true` — полноэкранная перебивка (камера гаснет, субтитры Y=1420). `lightTheme`
меняет тему сцены. Цветокоррекции камеры нет: исходник показывается как есть.

**Личное — не попадает в git и не передаётся дальше** (см. `.gitignore`):

- `public/projects/` — исходники, голос, транскрипции;
- `src/generated/` — композиции, которые пишет импорт;
- `src/local/` — личные композиции, если вы их заведёте;
- `.models/` — модель распознавания речи, качается сама.

Папки `src/generated` и `src/local` обязательны для сборки, поэтому `npm run dev`
создаёт в них пустые заглушки, если файлов нет. Удалять заглушки не нужно.

## Что применяется автоматически

- 1080×1920, частота кадров исходника; отдельные видео и голосовые клипы.
- Whisper small на CPU, русский язык, пословные тайминги, субтитры JSON и отдельные редактируемые текстовые клипы.
- Порог тишины вычисляется по шумовому фону и уровню речи конкретного файла; −35 dBFS остаётся резервным ручным значением. Границы слов берутся по звуку, а не по таймингам Whisper: хвост слова после глухой согласной («айфо-н») не режется, тишина, приписанная моделью к слову, — режется. Каждое звучащее слово проверяется на полноту после всех фильтров. Хвост после последнего слова короче 0,6 с не режется. Границы всё равно требуют прослушивания.
- Базовые субтитры импорта (стили 1–2): шрифт из профиля, 74 px, белый текст и тёмная подложка 88%, центр блока Y=1280; в режиме 50/50 — Y=960. Первичная группировка до двух слов; смысловые пары проверить.
- Приближение 100→110% за 0,8 с в начале. Далее удержание масштаба.
- Полупрозрачная маска 40% и направляющие. В экспорт они не попадают.
- Каждый запуск создаёт новую композицию: предыдущие ручные правки остаются.

Параметры меняются в `editing-profile.json` **до импорта**. Для уже созданного ролика правьте его клипы в Studio. `processVoice=false` сохраняет одобренную исходную обработку; `true` включает пробный профиль +3 дБ/фильтр/компрессор/лимитер. Музыка автоматически не добавляется.

## Правки в Studio

- Раскройте группу «Субтитры»: выберите фразу → Inspector → Text. Края клипа меняют длительность. Сверните группу для компактного вида.
- «Камера • общий масштаб и положение» → Transform: Scale, Offset, ромб Add keyframe. Проверьте глаза около верхней трети и отсутствие лишнего пространства над головой.
- Музыку добавляйте через Add asset. У выбранного Audio: Volume 0.1 = −20 дБ, 0.18 ≈ −15 дБ, 0.32 ≈ −10 дБ. Change source заменяет файл. Пустых музыкальных дорожек нет.
- Ctrl+Z отменяет, Ctrl+Shift+Z / Ctrl+Y возвращает. Исправление для Studio 4.0.525 устанавливается автоматически. В текстовом поле работает его история ввода. Возврат доступен после отмены, новая правка очищает ветку возврата.
- Studio показывает дерево слоёв, а не полноценные дорожки Premiere. Общей горизонтальной дорожки субтитров пока нет.

## Визуализации 50/50

Для подготовленных материалов создайте `scenes.json` с таймкодами **после удаления пауз**:

```json
[{ "start": 3.0, "end": 6.0, "asset": "D:/video/screenshot.png" }]
```

Импорт: `.venv\Scripts\python.exe scripts/import-video.py "D:/video/take.mp4" --scenes scenes.json`.

Для **уже собранного** ролика сцены добавляются без повторного распознавания речи:
`python scripts/apply-research.py rebuild <id>`. Материалы, найденные ИИ-агентом в интернете,
скачиваются в папку проекта командой `python scripts/apply-research.py fetch <id>` —
с проверкой лицензии и записью происхождения. Подробности в RESEARCH_WITH_CODEX.md.

Поддерживаются PNG/JPG/WebP и MP4/MOV без звука. Материал показывается сверху внутри безопасной области, человек снизу, субтитры Y=960. Масштаб и ключи материала редактируются в Studio. Кроп лица нужно проверить вручную. Вход компоновки прямой; движение самого материала задаётся ключами. Автоматическая генерация уместных иллюстраций, поиск материалов и расстановка эффектов по смыслу не включены — это следующий проход по AGENTS.md.

## Насмотренность: разбор чужих роликов

Чтобы графика не была дешёвой, проекту нужны разобранные примеры, а не просьба
«сделай красиво». Разбор делается один раз и остаётся в репозитории:

```
python scripts/study-reference.py "путь\к\референсу.mp4" --name имя-разбора
```

Скрипт раскладывает ролик на кадры, собирает контактные листы (страница кадров
одной картинкой), снимает текст с таймкодами и создаёт `references/имя.md` —
таблицу «реплика → что в кадре → приём → зачем». Дальше её заполняет агент или
человек, глядя на листы, и выписывает два списка: что забираем в проект и что
не забираем (чужие логотипы, чужие интерфейсы, приёмы не под нишу).

Сами кадры и звук остаются в `references/имя/` и в репозиторий не уходят —
попадает только конспект. Готовые разборы: `references/system-folders.md`,
`references/plashki.md`, `references/incognito.md`, `references/save-prompt.md`
(основа стиля автора).

Правила из разборов переносятся в три места: `MONTAGE_RULES.md` — что делаем
и чего не делаем, `src/scenes/tokens.ts` — цвет, размер, форма,
`src/scenes/motion.ts` — как объект появляется и живёт в кадре.

### Что уже собрано из разборов

Две витрины в студии показывают весь набор в движении — их открывают, чтобы не
изобретать заново то, что есть:

- **`Chips-Library`** — плашки, подписи происхождения, дерево с пунктиром,
  эмодзи. Код: `src/scenes/chips.tsx`.
- **`Scene-Interface`** — выделение слова под ударением, окно приложения,
  раскрытие меню по нажатию, набор текста. Код: `src/scenes/text.tsx`
  (`SelectedText`, `Mark`, `Typed`) и `src/scenes/window.tsx` (`AppWindow`,
  `MenuList`, `Ripple`, `Composer`, `Bubble`).

Окно в шаблоне — это форма окна, без чужого названия и логотипа. Точный
интерфейс продукта собирается по референсу и только в личном ролике: материалы
качает `scripts/apply-research.py`, он же записывает источник и условия.

## Проверка и восстановление

В `public/projects/Video-…` находятся source, voice.wav, words-original.json, captions.json, edit-map.json, review.json и снимок профиля. edit-map содержит оставленные и удалённые исходные интервалы. Исходник доступен для восстановления через Change source/trim.

Для точной повторной сборки со своими интервалами создайте `keep.json`: `[[0.68, 4.2], [5.0, 8.0]]`. Запуск с `--keep keep.json` создаст новую версию. `--transcript path/to/words-original.json` позволяет повторно использовать транскрипцию **того же исходника**. Не применять тайминги к другому видео.

Проверки: `.venv\Scripts\python.exe scripts/test-import.py`, `npx tsc --noEmit`.

## Экспорт и слабый ПК

EXPORT.cmd: компактный H.264 1080×1920 около 5 Мбит/с, AAC 128 кбит/с; черновик 540×960. Один параллельный поток рендера ограничивает потребление памяти, но не гарантирует быструю работу. Импорт не создаёт видеопрокси: исходник 4K может тормозить предпросмотр. Модель small работает на CPU; длинные записи обрабатываются дольше.

Шрифты субтитров берутся из системы и в архиве не распространяются. Правила использования Remotion зависят от его лицензии — проект её не заменяет.

Кадр камеры строится по лицу (OpenCV ставится в SETUP.cmd): видео всегда закрывает зону целиком, лицо по центру по горизонтали, глаза на 42% нижней половины в 50/50 и на 40% на весь экран; приближение ограничено `maxCameraZoomSplit`/`maxCameraZoomFull`. В начале ролика — наезд на 10% к лицу. Итог — в `review.json → framing` и константе `CAMERA` композиции. Без найденного лица кадр ставится по центру, причина пишется туда же.

Если для исходника сохранён согласованный пресет (`presets/<имя>`), повторный импорт того же файла восстанавливает монтаж, а не распознаёт заново; принудительно заново — `--fresh`. Новые видео проходят базовый импорт и требуют собственного визуального плана.

## Выбор стиля

Откройте Style1-Split (камера + графика 50/50) или Style2-Fullscreen (камера заменяется графикой в объяснении). Стиль автора (стиль 3: видео на весь экран, белые карточки на акцентах, крупные слова) — демо Style3-Author и движок `src/style3`; правила — MONTAGE_RULES.md, «Стиль автора». Для своего ролика агент копирует `src/style3/Style3Demo.tsx` в `src/local/`, подставляет видео, фразы из `scripts/style3-words.py` и свои сцены. В Inspector настроек композиции доступны fullScreenExplanation и lightTheme. Чтобы открыть настройки композиции, снимите выделение клипа. Значения профиля применяются к новым импортам; настройки текущего ролика сохраняются отдельно.

В новом видео подготовьте сцены через --scenes: тот же материал можно смотреть в двух компоновках. Без сцен обе компоновки показывают камеру. Автоматический поиск логотипов/информации не включён в Python-импорт; соответствующий этап для ИИ описан в AGENTS.md и MONTAGE_RULES.md.

Каждый новый импорт также создаёт `RESEARCH_REQUEST.md` и пустую таблицу `SOURCES.md`. Как запустить исследование через Codex, описано в `RESEARCH_WITH_CODEX.md`. Исследование отделено от локального импорта, чтобы источники были видны и проверяемы, а материалы не скачивались без проверки прав.

Шрифт субтитров и текста — в editing-profile.json → captionFont и textFont: по умолчанию `Coolvetica, Coolvetica Rg, Tahoma`. Coolvetica бесплатна, но лицензия Typodermic запрещает передавать её файл, поэтому в архиве его нет: скачайте свою копию с https://typodermicfonts.com/desktop и положите в `public/fonts-local/` (инструкция — README.md в этой папке) или установите в систему. Без неё — Tahoma. Подробности — «Шрифт монтажа» в MONTAGE_RULES.md. Inter лежит в public/fonts для демосцен шаблона. Старые композиции с явно заданным шрифтом сохраняются. Визуальные правила: раздел «Визуальная достоверность и чистота текста» в MONTAGE_RULES.md; точность интерфейсов проверяется агентом по референсу, не Python-импортом.

## Замена набора эмодзи

В проекте лежат эмодзи Apple (см. `public/emoji/SOURCES.md` про их лицензию).
Собраны они из файла цветного шрифта, и тем же способом набор пересобирается из
любого другого — например если нужен открытый или более крупный:

```
python scripts/emoji-from-font.py "C:\шрифты\AppleColorEmoji.ttc"
```

Файл шрифта берут со своего Mac (`/System/Library/Fonts/Apple Color Emoji.ttc`),
из резервной копии iPhone или из публичной пересборки
[samuelngs/apple-emoji-ttf](https://github.com/samuelngs/apple-emoji-ttf)
(в релизах лежит `AppleColorEmoji-Linux.ttf`, около 116 МБ, картинки до 96×96).
Лицензия MIT у той пересборки распространяется на её скрипты, а не на рисунки:
сам репозиторий пишет, что все эмодзи принадлежат Apple и ответственность за
использование шрифта от другой операционной системы лежит на вас. Без флагов картинки лягут в `public/emoji-local/` — эта папка в git не уходит, и
сцены начнут брать символы оттуда, не трогая общий набор. Так удобно держать
свои эмодзи, не меняя то, что видят остальные. Вернуться к общему набору:

```
python scripts/emoji-from-font.py <шрифт> --clear
```

Векторные цветные шрифты (Segoe UI Emoji из Windows, свежий Noto Color Emoji)

## Проверки

- `.venv\Scripts\python.exe scripts\test-import.py` — склейки (глухие согласные, хвост «айфон», тишина перед первым словом и внутри «слова», полнота слов) и кадр по лицу (нет пустых полос в 50/50 и на весь экран, лицо по центру, поворот телефонного видео, зона графики).
- `.venv\Scripts\python.exe scripts\check-frames.py <композиция>` — кадры готового ролика: камера без полей, графика в рамке и по центру зоны, субтитры 50/50 на 960. Лист кадров — `out/check/<композиция>/sheet.png`.
- `npx tsc --noEmit`, `npm run lint`, `node scripts/test-shortcuts.cjs`, `python scripts/test-research.py`.

Студия не падает из-за одной битой композиции: перед запуском `scripts/ensure-generated.cjs` не подключает те, у которых нет файла или импорта (например, удалённой сцены), и пишет какие.
Для монтажа GitHub не нужен: всё работает локально. ИИ-агент использует вашу собственную авторизацию.
