# Сюда — свой файл шрифта Coolvetica

Шрифт монтажа (крупные слова, субтитры, текст сцен) — **Coolvetica** от
Typodermic Fonts. Он бесплатный, но его лицензия запрещает передавать файл
другим людям и класть его в шаблоны, поэтому в шаблоне его нет: каждый
скачивает свою копию сам.

1. Открой официальную страницу бесплатных шрифтов Typodermic:
   https://typodermicfonts.com/desktop — скачай архив и распакуй.
2. Найди в нём файл Coolvetica Regular (`coolvetica rg.otf` или похожий).
3. Положи файл в эту папку и назови `Coolvetica-Regular.otf`
   (или `Coolvetica-Regular.ttf`, если он .ttf).
4. Перезапусти Studio (START-STUDIO.cmd).

Вместо шага 3 можно просто установить шрифт в систему (двойной клик по файлу →
«Установить») — Studio и экспорт возьмут его оттуда.

Без Coolvetica шаблон работает на Tahoma — монтаж не ломается, просто шрифт
другой. Файлы из этой папки в git и в архив для учеников не попадают.
